소녀전선: 뉴럴 클라우드 인형증 v6 — 올리는 법

1. index.html 과 assets 폴더를 저장소(GitHub / Cloudflare Pages)의 같은 자리에 넣으면 돼요.
   이미 올린 게 있으면 index.html 은 통째로 바꿔 붙여넣고, assets 폴더는 이걸로 바꿔 주세요.
2. 바꿔야 할 문구
   - 크레딧: index.html 의 CREDIT 한 줄
   - 오픈 날짜: index.html 에서 (오픈일) / (open date) / (上线日) / (公開日) 네 곳
   - 공지를 고치면 NOTICE_VERSION 숫자를 1 올리기 (보지 않기 한 사람에게도 한 번 다시 떠요)
3. 글꼴: assets/fonts 의 Do Hyeon, Share Tech Mono 는 무료(OFL) 글꼴이라 같이 올려도 돼요.
   HY헤드라인은 올리지 않고, 보는 사람 PC에 깔려 있으면 자동으로 써요.
4. 내 컴퓨터에서 index.html 을 더블클릭하면 그림이 안 뜰 수 있어요. 인터넷에 올린 주소로 열어 주세요.
